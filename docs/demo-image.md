# README image provenance

The image is reused unchanged from
[DLSS5 Everything's staged Android example](https://github.com/RazvanManolache/DLSS5-Everything/blob/1d830372ddfd35616b67533d0bf2d59dda4faea0/docs/readme-demos.md).

- Fictional 540×960 travel-app screen; generated landscape, invented interface.
- Actual PC-side `LanPhoenixBackend` output on RTX 5080; one pass, tone 1.35,
  structure 1.25, skin 0.70, using a separately supplied compatible model.
- Side-by-side phone framing is explanatory artwork.
- No physical phone, Android capture, TLS, Wi-Fi or live overlay was used to make it.
- No personal screen, credentials or device data appears.
- It illustrates the effect, not measured latency, streaming performance or
  guaranteed image improvement.
