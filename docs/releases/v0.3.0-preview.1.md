# Phoenix Link 0.3.0-preview.1

First separately published DLSS5 Everything Android companion. Android app name:
**Phoenix Link**, package `io.phoenixlink`, version code **3**.

- Android **14+**, **ARM64** APK, signed with a dedicated release identity.
- Windows host required: [DLSS5 Everything](https://github.com/RazvanManolache/DLSS5-Everything/releases).
  Set up compatible Phoenix components and a separately obtained model on the PC.
- Single-app and optional follow-active-app capture, floating live controls,
  Raw/Pyrowave transport, pinned TLS and encrypted saved pairing.
- No NVIDIA DLL, model, inference runtime or signing key is distributed.

## Install and trust

Download `PhoenixLink-0.3.0-preview.1-android-arm64.apk`. Verify its SHA-256 against
`SHA256SUMS.txt`. The release also includes the source ZIP and `VALIDATION.json`.

Public signing certificate SHA-256:

```text
7bde30ea384dbfdf40ea2d4e68c135a46f3df11578e7b905c37e67b4da568d68
```

A prior development-key install cannot be updated in place by this signing key.
Export anything needed first, uninstall that development build, then install this
APK. Uninstalling removes its saved connection data. Pair again from the PC's
Streamer page. This is a GitHub preview, not a Play Store distribution.

## Known limits

The PC performs inference. The phone still pays for capture, composition and
optional Vulkan codec work. This adds latency and does not increase game FPS.
Single-app touch-through normally blends at up to 80% opacity; follow mode uses
optional Accessibility access and pauses over protected/system windows.
Whole-display capture enhancement and DRM content are unsupported. Pyrowave
depends on compatible Vulkan drivers at both ends; Raw is an explicit option,
not a silent fallback. No audio, recording or input forwarding is provided.
